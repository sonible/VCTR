Detailed Description

template<is::anyVctrWithRealFloatValueType ContainerTypeParam>
class vctr::SplitComplexBase< ContainerTypeParam >

A container for complex values that stores the real and imaginary parts in two separate, equally sized buffers instead of interleaved like std::complex does.

This layout allows element-wise complex math to be evaluated without any dependencies between neighbouring elements, which is ideal for SIMD vectorisation. The math operations are available as allocation free free functions, see SplitComplexMath.h.

The ContainerTypeParam decides about ownership and size: Use SplitComplexVector for an owning, resizable container, SplitComplexArray for an owning container with a compile time size and SplitComplexSpan for a non-owning view. Use SplitComplexSpan<const T> for a read-only view.

Interleaved std::complex containers convert to split-complex containers through the constructor and assignment operator. To convert a split-complex container or expression back into interleaved values, use vctr::realImagToComplex.

Template Parameters
ContainerTypeParamAny VCTR container holding a real floating point value_type, e.g. Vector<float>, Array<float, n> or Span<float>. A const qualifier on the container type is ignored, use a const value type to make the elements read-only.
